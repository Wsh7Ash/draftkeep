## Known limitations
- The DOM content script, service worker and popup are not automated: there is no browser harness in this run. They are covered by structural tests and a manual procedure using `examples/test-form.html`.
- Only text-like fields, textareas and contenteditable elements are captured; selects/checkboxes/radios/files are not.
- `chrome.storage.local` is unencrypted; the privacy filter removes secrets but the store is not a vault.
- No icons are included.
- Manual verification steps require serving the test page over http (content scripts do not run on `file://` by default).
